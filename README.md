# .github

Organization-level files for **portable-genai**.

| Path | What it is |
|---|---|
| [`AGENTS.md`](AGENTS.md) | The working agreement for agentic coding across every repository: architecture rules, invariants, the gate, house style, and where the work is written down. |
| [`profile/README.md`](profile/README.md) | The organization front page: what these repositories are, how they depend on each other, and the principles they are mapped against |
| [`common-base-practices.md`](common-base-practices.md) | The shared checks, A1 to G7, that every repository's `docs/practices-audit.md` scores itself against |
| [`SECURITY.md`](SECURITY.md) | How to report a vulnerability, what is enforced in the code, and what assurance does not exist |
| [`CONTRIBUTING.md`](CONTRIBUTING.md) | The contribution bar, for repositories that do not carry their own |

`SECURITY.md` and `CONTRIBUTING.md` are community health files: GitHub applies them to
every repository in the organization that does not ship its own copy.
